# Extraction structurée de l'observation vision — Sama Agent (v1)

Une vision IA a décrit un document administratif fourni pour une demande de permis
de conduire au Sénégal. À partir de CETTE SEULE description, réponds en STRICT JSON :

{"contentType": "carte|medical|certificat|photo|autre",
"readable": true|false, "matchesExpected": true|false,
"reason": "phrase factuelle", "confidence": 0..1}

Règles :
- contentType : "carte" si carte d'identité ; "medical" ou "certificat" si certificat
  médical ; "photo" si photographie ; sinon "autre".
- readable : false si la description signale flou, illisible ou texte non fiable.
- matchesExpected : true si le document paraît attendu pour la démarche et net.
- confidence : probabilité d'observation correcte (0..1) — jamais maximale sur un
  document flou ou mal décrit.
- reason : phrase factuelle issue de la description (jamais de validation officielle).
